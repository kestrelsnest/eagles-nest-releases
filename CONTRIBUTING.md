# Contributing to Overseer

Thank you for helping. Bug reports, ideas, translations, screenshots and code are all welcome.

## Reporting a bug or an idea

Open an [issue](https://github.com/kestrelsnest/overseer-releases/issues) with what you did,
what you expected and what happened. For a server problem, add the `DCB (Main)` lines from the
server's `dcs.log` — and remove passwords, IP addresses and player names first.

## What not to send

- Files copied from DCS World or its modules (maps, charts, imagery, data cartridge tables,
  unit data): Overseer reads those from each user's own install and never ships them.
- Third-party missions or scripts (Foothold, MOOSE …) — link to them instead.
- Passwords, server addresses, player names or Discord IDs.
